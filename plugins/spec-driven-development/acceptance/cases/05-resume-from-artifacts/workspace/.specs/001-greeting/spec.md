# Spec: Greeting modules

## Intent
Provide two stable greeting modules.

## Requirements

### REQ-001: First greeting
Return the first greeting.

#### Scenario: first greeting
- Given the first module
- When its function is called
- Then first is returned

### REQ-002: Second greeting
Return the second greeting.

#### Scenario: second greeting
- Given the second module
- When its function is called
- Then second is returned

## Non-goals
- Localization.
