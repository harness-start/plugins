# Mobile Guards

Target-native mobile checks for generated Dart and Apple lockfiles, Dart analysis, Swift encoding and concurrency patterns, Objective-C/UIKit patterns, and Android/Flutter/Apple environment discovery.

The nine source hooks are consolidated into three event entries and three check modules. Scripts run directly on Node.js 20+ with no package installation, compilation, bundled SDK, or vendored source tree. Dart analysis runs only when a host `dart` executable is already available.
