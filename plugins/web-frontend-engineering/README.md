# web-frontend-engineering

Orchestrates React, Vue, and Angular engineering and guards JavaScript package-manager state.

- Skill: `web-frontend-engineering`
- Required community Skills: `vercel-react-best-practices`、`vercel-composition-patterns`、`angular-developer`、`vue-best-practices`、`vue-router-best-practices`、`vue-testing-best-practices`
- PreToolUse: domain-owned dependency/generated state
- PostToolUse: bounded syntax/configuration checks
- Config: `.web-frontend-engineering.mjs`

Package-manager commands remain allowed when they do not explicitly target a protected path. Live acceptance is Docker-only.
