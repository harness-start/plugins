# Logo Color & Accessibility / 标志色彩与可访问性

This Skill is a **read-only bilingual adviser**. It has no project writer, review, release, network, or external-key authority. 本 Skill 只提供中英文建议，不能写项目、签发评审或执行发布。

Read [Logo color checks](references/logo-color-checks.md). Return a bounded Result Card covering:

- primary, mono, and reverse behavior before decorative color;
- sRGB source values plus documented CMYK/spot-color conversion guidance;
- contrast for surrounding UI or text without pretending that a logo itself is body text;
- color-vision and grayscale differentiation when color carries meaning;
- gamut risks and a concrete verification or recovery path.

Do not claim legal trademark clearance, press accuracy without a physical proof, or accessibility from hex values alone.
