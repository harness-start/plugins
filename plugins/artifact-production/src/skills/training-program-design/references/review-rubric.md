# 评审量规

评审必须覆盖以下七项，并为每项给出项目内精确锚点与可核查证据：

1. `alignment`：目标、活动、评价和迁移一致。
2. `audience-variability`：差异有证据，诊断、支架和拓展能响应差异。
3. `practice`：每个 outcome 都有足量、贴近工作场景的练习。
4. `assessment`：标准可观察，能证明 outcome，而不只是记忆或满意度。
5. `facilitation`：讲师能据表现调整支架、节奏、分组与反馈。
6. `material-consistency`：讲师指南、学员手册、练习评价与 slide outline 由同一源生成且没有矛盾。
7. `transfer`：培训后有定时、可执行、可反馈的工作迁移安排。

blocking finding 表示当前阶段不能成立；warning 表示可以发布但必须披露的风险；note 是非阻断改进建议。每条 finding 必须含 severity、exact anchor、concrete evidence 与 verifiable fix。
