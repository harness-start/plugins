# 培训设计方法

## 1. 从工作表现倒推

先写参与者培训后要完成的真实任务，再写可观察证据。Outcome 使用动作、条件和质量标准，避免“了解、熟悉、掌握”这类无法直接验证的词。

## 2. 用证据描述差异

只记录会改变设计的差异，例如工具经验、领域知识、语言、设备、权限、无障碍需求和工作角色。每个差异必须附证据来源；资料不足时设计一个五到十分钟、低风险且不公开排名的共同诊断。

## 3. 同任务、可变支架

混合水平受众共享一个与 outcome 对齐的 common task：

- entry supports 降低非目标负担，例如术语卡、完整示例、分步检查表、结对操作；
- stretch extensions 增加推理、迁移或约束，例如故障诊断、边界案例、性能/安全权衡；
- facilitator moves 说明讲师观察什么、何时加支架、何时撤支架、如何避免高手代做。

支架不能替代核心表现，拓展也不能变成无关的“多做几题”。

## 4. 先练后评

每个 outcome 至少被一个 activity 练习，并被一个 assessment 检查。评价标准必须可观察；选择题可以检查先备知识，但不能单独证明操作或判断能力。

## 5. 设计迁移

在培训结束前形成一个具体承诺，并在明确时间点安排真实任务、同伴反馈、主管观察或复盘。培训满意度不是迁移证据。

## 6. 改编而非换皮

`adapt` 模式逐项记录原材料的 retain、modify、remove 及理由。保留目标一致且证据仍有效的内容；修改受众、工具或约束已变化的内容；删除与 outcome 无关、过时或重复的内容。
