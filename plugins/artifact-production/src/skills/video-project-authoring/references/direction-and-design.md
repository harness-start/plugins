# Direction and design

Freeze one motion thesis: what moves, from which state to which state, and what claim that transformation supports. Freeze a communication core with intent, audience outcome, exact retell target, one signature cue anchored to a current storyboard beat, a causal semantic link, invariants, and prohibited drift. Every storyboard beat records its narrative job, contribution to the core, moving object, visible state change, camera or layer motion, text role, assets, and slide-like failure risk.

The design system defines semantic color roles, type roles, safe areas, caption treatment, motion durations and easing, spring response, stagger, blur, camera depth, transitions, and audio targets. Reuse a small motion vocabulary with deliberate variation. Text supports the visual argument; it does not replace it.

When shot planning is required, `plan.shots.json` covers every storyboard beat with one pinned catalog selection or a reasoned custom beat. The storyboard approval digest includes the shot plan. A staged snapshot is reference material; the project-owned `src/visual/` implementation and declared review frames remain the evidence subject.
