# Generated input asset boundary

Use image generation only to create a visual input asset for `poster-project-authoring`. This adviser has no provider, rendering, writer, review, or release authority.

## Asset contract

- Generate imagery, texture, spatial structure, or material studies without final display copy.
- Reserve the declared focal box and quiet regions from `plan.art-direction.json`; do not invent a second composition contract inside the asset.
- Keep the asset useful when cropped and layered. Avoid mockup frames, decorative metadata, pseudo-text, signatures, logos, and QR-like marks.
- Describe one primary cultural structure, one supporting cue, palette roles, material response, light direction, and exclusions.
- Record the tool, model, exact prompt digest, file digest, source type, and asset role in `plan.assets.json`.
- Treat the asset as replaceable. Typography, title/media depth, masking, safe areas, and final layout stay in deterministic source layers.

## Prompt scaffold

```text
Create a copy-free visual input asset for a contemporary regional-culture poster.
Primary cultural structure: {PRIMARY_STRUCTURE}.
Supporting cue: {SUPPORTING_CUE}.
Material and surface response: {MATERIAL}.
Light direction, quality, and contrast: {LIGHTING}.
Palette roles: {COLOR_ROLES}.
Composition support: {FOCAL_BOX_AND_QUIET_REGIONS}.
No words, glyphs, logos, signatures, captions, QR-like marks, mockup frames,
tourism collage, postcard panorama, or unrelated traditional symbols.
```

Inspect the asset for cultural specificity and contamination before registration. Final correctness is established only after deterministic rendering, probes, independent review, and release closure.
