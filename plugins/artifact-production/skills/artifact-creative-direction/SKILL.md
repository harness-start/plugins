# Artifact Creative Direction

## When to use

- Use before initialization when the user requests alternatives, a fresh direction, or help escaping repetitive artifact concepts.

## Constraints

- Remain read-only: do not write project files, invoke artifact writers, perform review, release an artifact, or issue receipts.

This is read-only pre-init advice. It does not write the artifact, initialize a project, review or release the artifact, or issue evidence and receipts.

## Method

1. Restate the audience, job, fixed constraints, open variables, existing brand or source evidence, and what feels repetitive or blocked.
2. Choose exactly one technique:
   - **assumption inversion** for a load-bearing convention;
   - **concept fan** when the proposed solution may be solving the wrong-level problem;
   - **mechanism analogy** for a derivative direction that needs a different operating principle;
   - **SCAMPER** when a coherent seed needs transformation;
   - **bounded stimulus** when the space is empty and needs one relevant constraint.
3. Generate a maximum of three live directions. Make them mechanism-distinct, not cosmetic variants. For each, state its mechanism, observable implications, cost, risk, and fastest validation.
4. Keep convergence visible: list any duplicate, forced route, or dead end that was abandoned and why. Do not silently replace a weak option to fill a quota.
5. Compare live directions against the audience job, brief, retell target, constraints, and signature cue. Recommend one only when those criteria distinguish it; otherwise ask one bounded selection question.
6. Return a compact advisory brief for the owning authoring Skill. Advice is not evidence and creates no schema field; the author integrates the chosen direction into the same existing brief before initialization.
