# Existing presentation boundary

`presentation-storyboard` only advises on new decks created from scratch under the `presentation-production` v2 project contract. Editing an existing PPTX, reusing an uploaded template, XML surgery, or text extraction is outside this adviser's scope.

Do not copy, unpack, patch, or rewrite an existing deck. Return the unsupported boundary to the orchestrator so it can explain the limitation or select a separately authorized workflow.
