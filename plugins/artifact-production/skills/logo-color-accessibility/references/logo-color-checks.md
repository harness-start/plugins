# Logo color checks

1. Verify the mark remains identifiable in solid black and solid white.
2. Record sRGB source values and the target display/print profile. Use perceptual spaces such as OKLCH for exploration, but inspect the actual exported sRGB bytes.
3. For UI labels or text adjacent to the logo, measure WCAG contrast against the actual background. Do not apply body-text thresholds to decorative logo outlines as a substitute for visual inspection.
4. When color communicates state or category, add shape, label, texture, or another non-color cue and inspect common color-vision simulations.
5. Treat CMYK and spot values as production guidance until a printer profile and physical proof confirm them.
