# Limited-palette poster direction

This Skill is a **read-only** adviser. It cannot write project files, run scripts, call an image service, create protected evidence, stamp review, or release. The main `$poster-project-authoring` workflow decides whether and how to integrate its advice.

## Build a decision-complete direction

Translate the brief into these executable dimensions:

1. **Communication scene**: audience, viewing distance, carrier, aspect ratio, and the one response the poster should cause.
2. **Symbolic subject**: one subject-specific object or relationship that can carry the idea without a literal scene collage.
3. **Composition**: dominant axis, focal bbox, mass-to-void target range, scale contrast, and intended foreground/midground/background order.
4. **Letterform system**: type class, stroke profile, structural gravity, spacing rhythm, edge finish, and the exact relationship between display type and imagery.
5. **Palette and material**: two to five semantic colors, paper or ink behavior, halftone/grain policy, and an explicit cleanliness limit.
6. **Negative rules**: prohibited cliches, undeclared copy, decorative metadata, style mixing, and any visual treatment that would obscure required text.

Do not accept “高级”, “复古”, “大师感”, “有设计感”, or a named creator as a complete direction. Replace each with observable choices from the six dimensions above.

## Select one composition family

Read [Composition families](references/composition-families.md) and choose one family. Do not combine families unless the brief explains the causal benefit.

- `single-symbol`: one object, a restrained text block, and a declared void range.
- `figure-ground`: one silhouette or container whose negative space reveals a second subject-specific reading.
- `scale-contrast`: a small foreground subject against one dominant environmental mass.
- `type-architecture`: exact display lettering acts as structure, boundary, mask, or path rather than a label placed afterward.
- `layered-atmosphere`: one primary subject and no more than two depth-supporting layers.

## Return an adviser result

Return one recommended direction and one materially different fallback. For each include:

- composition family and rationale;
- dominant axis and mass-to-void target range;
- symbolic subject and why it is non-substitutable;
- exact letterform dimensions and `front|behind|mask|interrupt` image/type relation;
- palette roles and texture limits;
- required copy and prohibited invention;
- smallest useful review thumbnail;
- falsifiable failure conditions.

Use [Carrier notes](references/carrier-notes.md) when the artifact is a book cover, album cover, social card, or event poster. Never promise generation, availability of a model, or a visual outcome from prompt formatting alone.
