# Design system

Define semantic colors, not decorative swatches. Every text role names a local or pinned-package font, integer pixel size, weight, line height, and intended use. Define safe area, base spacing unit, contrast pairs, and a maximum information density appropriate to the profile.

Use one focal relationship, one dominant axis, one interruptor, and a deliberate mass-to-void ratio. Typography must carry hierarchy without relying on size alone. Supporting copy is exact and useful; generated pseudo-text, decorative QR codes, fake metadata, and placeholder labels are forbidden.

Do not encode meaning by color alone. Do not use remote fonts or runtime URLs. Any added font or image is an asset with provenance and a content digest.
