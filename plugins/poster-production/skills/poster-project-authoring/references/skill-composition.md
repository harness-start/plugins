# Skill composition

The orchestrator owns all files and decisions. Bundled first-party advisors return a compact brief containing recommendation, rationale, rejected alternatives, risks, and measurable checks. They never write, render, review, or release.

| Worker | Source policy | Phase | Contribution |
|---|---|---|---|
| `poster-regional-culture` | bundled first-party | art direction | cultural candidate pool, specificity, anti-stereotype and text-removal checks |
| `poster-mondo` | bundled first-party | art direction | symbolic compression, limited palette, negative space and print-material advice |
| `poster-academic` | bundled first-party | academic structure | story compression, figure priority and distance scanability only |
| `poster-visual-critique` | bundled first-party | design system and critique | hierarchy, typography, spacing, palette and polish |

Retry an unavailable specialist once. Then record `unavailable`, use bundled rules, and disclose the fallback. Never execute advisor scripts or API clients.
