# Quality gates

Lint checks the staged JSON contracts, exact Skill revisions, approvals, rights, frame projections, source ownership, and deterministic Remotion wiring. Render measures each unit and final output before promotion. Probe measures container/streams, duration, frame boundaries, captions, audio, and declared reference fidelity.

Automated checks prove structural and media facts only. Narrative clarity, aesthetic quality, factual truth, rights truth, and human approval identity require independent review. A successful command or non-empty MP4 is not release evidence.
