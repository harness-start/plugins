# Direction and design

Freeze one motion thesis: what moves, from which state to which state, and what claim that transformation supports. Every storyboard beat records its narrative job, moving object, visible state change, camera or layer motion, text role, assets, and slide-like failure risk.

The design system defines semantic color roles, type roles, safe areas, caption treatment, motion durations and easing, transitions, and audio targets. Reuse a small motion vocabulary with deliberate variation. Text supports the visual argument; it does not replace it.
