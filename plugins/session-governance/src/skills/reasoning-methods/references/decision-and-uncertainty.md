# Decision and uncertainty

1. State the objective, hard constraints, and who bears each consequence.
2. Separate reversible choices from one-way doors. Buy information before an irreversible commitment when its cost is justified.
3. Use a base rate only when a defensible reference class exists; describe why it is comparable. Never invent a numeric prior for presentation.
4. Name the opportunity cost of the leading option and steelman the strongest feasible alternative.
5. Run a short pre-mortem: assume the choice failed, then identify the earliest observable cause.
6. Expose the load-bearing assumption, its plausible range, and the cheapest kill test.
7. Record an update condition: the observation or threshold that would change, pause, or reverse the decision.

Expected-value arithmetic is useful only when the inputs and consequence scale are supportable. Otherwise use ranges and ordinal comparisons and label the uncertainty.
