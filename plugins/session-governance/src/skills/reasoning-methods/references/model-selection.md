# Model selection

Choose **NONE or one primary structure**. A named model earns its place only when it changes the next observation, calculation, or choice.

| Task signal | Primary structure | Decisive question |
| --- | --- | --- |
| Quantifiers, feasibility, or boundary cases | exact | What counterexample or deterministic oracle can reject the candidate? |
| An observed failure with several causes | causal | Which cheap observation discriminates between the live hypotheses? |
| A statement whose truth matters | claim-evidence | What evidence would update or defeat this scoped claim? |
| A consequential choice | decision | Which assumption, opportunity cost, or irreversible consequence changes the choice? |
| Behavior emerging over time | system | Which feedback loop, delay, incentive, or state transition explains the behavior? |
| A stuck or derivative option set | divergence | Which mechanism-distinct route serves the same job differently? |

Add a second structure only when it tests a distinct failure mode. Do not count models, make every task traverse a catalogue, or use model voting as confidence.
