# Thinking-method provenance

The reasoning-method references, `grill-me`, and `socratic-tutor` are original synthesis written for this plugin. They were informed by an audit of the following public prior art at pinned revisions; no repository is fetched or required at runtime, and no wording is copied verbatim:

- `tjboudreaux/cc-thinking-skills` — `7b8fece`
- `mattnowdev/thinking-partner` — `ce95b62`
- `kcchien/model-thinking` — `c4027be`
- `danium/lateral-thinking` — `bde713d`
- `paulbricman/k-probes` — `3e98b87`
- `Johna2an/critical-thinking` — `8bc32ac`
- `jrcruciani/baloney-detection-kit` — `1c2ce56`
- `soheilmomeniii/blindspot-check` — `3e998ac`
- `bevibing/socrates-skill` — `becb2e5`
- `Jekudy/grillme-skill` — `f9df31c`

`k-probes` was reviewed as an MPL-licensed prompt-generation research project, not treated as an installable Agent Skill. `grillme-skill` was used only as prior art because its repository advertised MIT terms in its README but did not contain a license file at the audited revision.
