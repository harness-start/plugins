Acceptance cases cover both the mechanical Hook and a rendered responsive outcome; they do not claim to automate taste.

- `01-hard-offset-shadow`: write a UI CSS file with a zero-blur offset shadow; the PostToolUse additional context must name `HARD_OFFSET_SHADOW`.
- `02-responsive-system`: improve a small account page, require system and accessibility primitives in source, then render desktop and mobile screenshots with Chromium inside the host-acceptance container.
