# Interface craft

This Skill is the only entry. Load same-plugin companions; never load community `impeccable` or `vendor-skills`.

## Route

1. For a new or redesigned surface, read `$interface-craft-floor` before editing UI.
2. For a read-only review, read `$interface-visual-critique`.
3. After edits, honor Hook findings. Mechanical codes (`HARD_OFFSET_SHADOW`, `GRADIENT_TEXT`, `EYEBROW_KICKER`, `SECTION_NUMBER_DECORATION`, `REPEATING_GRID_BACKGROUND`) are facts about the current file. Taste judgments stay in the critique Skill.

## Honest limits

- This plugin does not write poster, deck, Remotion, or logo artifacts.
- It does not protect lockfiles or replace `web-frontend-engineering` syntax gates.
- Parse errors and non-UI files fail open. Hook activation is not proof the interface is good.
