# Interface visual critique

This Skill is **read-only**. It cannot write UI files, run live browsers, or stamp a product review.

Record findings with `file:line`. Check:

1. One primary action and a stable hierarchy.
2. Contrast and non-color encoding.
3. Type scale and measure.
4. Spacing groups before extra containers.
5. Empty, loading, and error states.

Do not recommend community `$impeccable` commands or live-server scripts.
