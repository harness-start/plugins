# Go Runtime Guards

Go lockfile deny + encoding/debt/syntax reports

## Events

- **PreToolUse**: deny direct lockfile writes (`go.sum`)
- **SessionStart**: report `go-lint-coverage-primer` gaps
- **UserPromptSubmit**: inject consolidated `go-env-detector` facts once per day
- **PostToolUse**: report encoding, debt, syntax, and structured `go-tool-output-primer` summaries
