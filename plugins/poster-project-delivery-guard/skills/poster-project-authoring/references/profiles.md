# Profiles

| Profile | Default | Required direction | Specialist |
|---|---:|---|---|
| `regional-culture` | 1200×1600 | one non-substitutable cultural mechanism; remains region-specific when labels are hidden | `regional-culture-poster` |
| `mondo` | 1080×1920 | one original symbol, 2–5 colors, negative-space or scale tension, screen-print material | `qiaomu-mondo-poster-design` |
| `editorial` | 1200×1600 | brief-driven typographic hierarchy, grid and reading rhythm; never a fixed six-cell template | bundled OpenDesign-derived principles |
| `academic` | 2400×1200 | one-sentence takeaway, large evidence, sparse copy and distance scanability | `cvpr-2026-poster` |
| `custom` | explicit | one measurable communication objective and original visual relationship | `impeccable` |

Dimensions are digital pixels and may be overridden in the variant manifest. Academic ignores conference branding, deadlines, prices, print size, PDF, and template assets.
