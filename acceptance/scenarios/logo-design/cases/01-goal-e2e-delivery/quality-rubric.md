# Quality rubric — Northline logo e2e

Score each row 0–2 (0 = missing/fail, 1 = partial, 2 = solid). Every required row must score **2**; totals and averages cannot compensate for a weak row. `expect.sh` reads the independent, digest-bound review rather than inferring quality from file presence.

| Criterion | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Brief fidelity | Ignores logistics/cold-chain or B2B tone | Some brand fit, generic SaaS | Clear precise/calm/modern cold-chain logistics read |
| Concept divergence | One idea only or near-duplicates | 2+ directions but weak contrast | Multiple genuinely different directions before lock |
| Vector craft | Raster/text-in-SVG/system font outline | Native SVG but rough geometry | Clean self-contained paths, single focus, scales |
| Black-and-white first | Only color showpiece | Partial mono | Mark/wordmark work in pure mono/reverse |
| Delivery profile | Missing practical outputs | Partial exports | SVG family, transparent sizes, icons, specimen/mockup, print notes, and Figma fallback |
| Semantic integration | Generic decoration | Brand idea described but loosely attached | Brand meaning is inseparable from the chosen form |
| Optical restraint | Rigid/ornamental or noisy | Some correction | One memory point with measured optical correction and restraint |

**Not auto-proven by hooks:** trademark clearance, market uniqueness, final aesthetic excellence.
